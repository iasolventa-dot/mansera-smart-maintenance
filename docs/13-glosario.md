# 13 · Glosario

**GMAO/CMMS** gestión del mantenimiento asistida por ordenador (PGMWin). **ERP** gestión empresarial (A3ERP). **OT** orden de trabajo. **Preventivo/Correctivo/Predictivo** tipos de mantenimiento. **SLA** nivel de servicio contratado. **CAE** coordinación de actividades empresariales (PRL). **PRL** prevención de riesgos laborales. **SCADA/PLC/IoT** sistemas y sensores industriales. **API** forma de que un programa hable con otro. **Webhook** aviso que una app envía cuando ocurre algo. **Rate limit** máximo de peticiones permitido. **Conector** módulo nuestro que habla con una app. **Gateway** agente instalado en la red de MANSERA que ejecuta operaciones de forma segura. **Golden record / enlace** identificador común de una misma entidad en varias apps. **Propuesta** cambio pendiente de aprobación humana. **Idempotencia** repetir una operación no la duplica. **RLS** seguridad a nivel de fila en la base de datos. **RAG** IA que responde buscando antes en documentos propios. **Anomalía** comportamiento fuera de lo normal; **predicción** estimación de un fallo futuro (no es lo mismo). **ADR** registro de decisión de arquitectura. **Spike** prueba corta para eliminar una incertidumbre técnica. **MVP** versión mínima demostrable. **PWA** web instalable que se comporta como app.
