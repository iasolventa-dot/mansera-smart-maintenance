# ADR 0003 · Gateway on-prem saliente
- **Fecha:** 2026-10-13 · **Estado:** propuesto (depende de Q1 y del spike M1)
**Decisión:** si PGMWin/A3 están en red local, agente Node de solo conexiones salientes con trabajos firmados y lista blanca. **Alternativas:** túnel (Cloudflare/Tailscale), VPN sitio-a-sitio, exposición directa (descartada). Decidir tras Q1/Q6 (ciberseguridad). Ver skill `onprem-gateway`.
